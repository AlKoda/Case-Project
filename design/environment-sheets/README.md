# Environment asset sheets

Location reference, one sheet per place. Each carries a main view, alternate
angles, and a strip of individual props and details cut out separately.
**Source material, not runtime assets** — backgrounds the game loads live at
`assets/backgrounds/<scene>.png`.

Mostly 1448 × 1086; `locations-atlas` is 1672 × 941.

## Notes

These are contact sheets, so the main view on each is roughly 1000 px wide —
enough for a background at the game's current scale, but it will not survive
being blown up to 1920. Cut from the largest panel on the sheet, not a thumbnail.

Several of these match the case as written: `riverside-pier` and
`corniche-waterfront` are the Mutrah harbour the Al-Manar stands on, and
`interrogation-room`, `evidence-room` and `archive-room` cover the interview
scenes directly.
